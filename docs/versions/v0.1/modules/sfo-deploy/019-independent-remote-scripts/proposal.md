# 独立远端生命周期脚本提案

Risk profile: ./risk-profile.yaml

## Workflow Tier Judgment

- Proposed tier: high-risk
- Final tier: high-risk
- Tier rationale / triggered boundaries:
  本变更移除远端脚本对框架运行库的依赖，改变脚本执行协议、配置密钥与模板消费方式，并影响已有脚本及历史发布快照的兼容性；用户同时明确要求自动完成，因此触发运行时集成、公开契约、部署兼容性与
  auto-pipeline 边界。
- Proposal and tier confirmation: 已确认；用户启动语句为“确认，自动完成”，确认本提案并授权从 design
  开始自动完成实现、测试与验收，不需要逐阶段再次确认。

## Background and Goal

集群生命周期配置允许使用可编程脚本，但这些脚本应当是自包含程序，不应导入或依赖 sfo-deploy 框架上传的
`sfo_deploy.ts`。sfo-deploy 只负责本地规划、输入准备、SSH/SCP
投递、远端进程启动、权限约束、结果收集与清理。

## Scope

### In scope

- 停止生成和上传远端 `sfo_deploy.ts` 框架辅助模块。
- 保留普通进程输入契约：独立脚本可通过 `DEPLOYMENT_CONTEXT_PATH` 自行读取当前步骤 JSON
  数据，不调用框架函数。
- 迁移仓库内所有当前 TypeScript 生命周期脚本，使其不再导入 `DeploymentContext` 或其他框架源码。
- 保持当前脚本权限白名单、制品投递、模板投递、配置密钥最小暴露、日志脱敏和远端临时目录清理边界。
- 更新公共说明、配置指南、示例和测试，验证远端工作区不含框架源码且独立脚本仍可完成部署动作。
- 明确记录既有依赖 `sfo_deploy.ts` 的外部脚本及历史快照需要迁移的兼容性影响。

### Out of scope

- 不移除 Deno 2 远端运行时要求，也不新增 shell、Python 或其他脚本语言。
- 不改变生命周期动作集合、环境/App 规划顺序、SSH 地址选择或制品下载 provider。
- 不引入常驻集群 Agent、远端安装 sfo-deploy、网络/npm 动态依赖或新的秘密存储系统。
- 不承诺旧的、仍导入 `sfo_deploy.ts` 的发布快照可在新版本中无修改回放。

### Boundary with neighboring modules

控制端仍拥有上下文 JSON 的生成、秘密选择与脱敏；远端生命周期脚本只依赖
Deno、标准进程环境、普通文件和声明允许的系统命令。`remote_context.ts`
可继续作为控制端上下文编码与公共本地 API，不能再作为远端框架源码注入来源。

## Requirement Review

该要求合理，能够恢复清晰的控制面/远端脚本边界，并避免把框架实现隐式部署到集群。选定方向是“标准数据协议、零框架代码依赖”：继续用权限受限的上下文文件传递步骤数据和秘密路径，使执行器不必把秘密放进命令行，同时由每个独立脚本自行解析和处理。主要代价是脚本需要少量自有解析/模板逻辑，且旧脚本与旧快照存在明确迁移成本；不采用通过
`deno eval` 或 stdin 注入辅助源码的变体，因为那仍然是远端执行框架代码，只是隐藏了文件形态。

## Success Criteria

- Concrete user-visible or system-visible result: 任一新计划执行时，远端临时工作区不出现
  `sfo_deploy.ts` 或其他框架源码，生命周期脚本仍可通过普通输入完成环境检查、安装、配置、App
  部署和服务生命周期动作。
- Required evidence: TypeScript 类型检查；执行器单元/DV
  测试；示例消费者与脚本测试；删除的远端运行库符号与导入路径扫描；任务级 `test-run.py`
  成功制品；独立缺陷发现验收。
- Explicit non-goals:
  不保证依赖旧辅助模块的外部脚本或历史快照无迁移回放，不扩展脚本语言或安装常驻远端组件。

## Risks

- 公开/兼容性：既有远端脚本导入路径被移除，属于有意的迁移型变化。
- 安全：独立脚本自行解析秘密和模板，必须继续限制上下文文件权限、Deno 文件/进程/网络能力及日志脱敏。
- 运行时：执行器准备、上传、执行和清理顺序改变，必须覆盖取消、失败、检查未满足与工作区清理。
- 发布/回退：历史快照若包含依赖旧辅助模块的脚本，不能假定在新执行器下继续成功。
