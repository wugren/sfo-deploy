## Background and Goal

检查 sfo-deploy 部署逻辑是否存在问题，优先识别可导致命令注入、越权、秘密泄露、任意文件读写或不可信制品执行的缺陷，同时检查失败恢复、并发及回退一致性。

## Scope

- 检查 src/ 下配置校验、规划执行、SSH/SCP、远端运行时、制品下载缓存和解包、秘密处理、配置发布、systemd 管理、历史快照及回退调用链。
- 结合 tests/、示例配置和文档核对预期行为与信任边界。
- 使用本地隔离、可控输入的验证及相关既有测试确认候选问题；不连接实际部署节点。
- 交付中文问题清单、具体代码位置、触发条件、影响与修复建议。
- 非目标：直接修复产品代码、真实部署、真实凭据读取、在线攻击或全面依赖漏洞扫描。

## Requirement Review

- 请求合理；部署工具涉及远端执行和特权文件操作，需沿输入到危险操作的实际路径检查。
- 区分可信部署配置固有权限与跨信任边界缺陷，避免把理论风险直接认定为漏洞。
- 优先验证严重问题；不得以测试通过证明不存在漏洞。无法验证的问题明确标注证据缺口。
- 待澄清问题：无。

## Success Criteria

- 对关键调用链记录覆盖情况；确认的问题具有文件行号、严重程度、具体前提、影响及修复方向。
- 区分已确认问题、待验证风险与未覆盖范围；明确实际执行的验证及结果。
- 完成 standard 变更记录与任务本地 completion-report.md，向用户给出按严重程度排序的中文结论。
- 产品源码与实际部署环境不因审查而改变。

## Risks

- 本地审查不能证明真实节点配置及权限正确，真实环境相关结论需要明确适用条件。
- 测试可能启动子进程或写临时文件；执行前阅读相关测试，使用隔离目录和伪造秘密，避免实际 SSH、发布或服务变更。
- 审查过程和报告不得包含真实秘密；仅以字段名及合成输入说明问题。
